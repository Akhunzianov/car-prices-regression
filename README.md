# Выбор датасета

Хотелось поработать с задачей регрессии, а также разноплановые признаки в таблице показались довольно интересными и с ходу не было понятно как все делать. Также сама по себе задача понять цену по характеристикам показалась довольно интересной.

# Гипотезы

- Если убрать признаки цвета интерьера и экстерьера, валидационная MAE изменится в пределах 2%, так как эти фичи не так сильно влияют на стоимость
- Дерево с подобранной глубиной достигнет валидационного MAE ниже чем линейная регрессия, так как цена опирается на нелинейные соотношения
- Предсказывать `log(1 + p)` где `p` это цена даст валидацонное MAE ниже чем просто предсказание цены, так как очень дорогие машины не будут так сильно влиять на модель
- Дерево без ограничений на глубину заоверфиттится больше чем средней глубины, без ограничений MAE будет меньше на трейне, но больше на тесте
- Если достать из описания мотора доп параметры (например, лошадиные силы, количество цилиндров и тд), то валидационное MAE уменьшится
- Добавление бренда и модели в модель даст меньший валидационный MAE чем без них


# Результаты
- MAE изменилась немного больше (~ -3% для всех моделей), но по смыслу результат получился такой же
- Гипотеза не поддтвердилась. Для большинства наборов признаков линейная регрессия оказалась лучше, но для некоторых дерево дало результаты лучше. Сама по себе нелинейность не гарантирует лучших результатов
- Гипотеза поддтвердилась
- Гипотеза поддтвердилась: с увеличением глубины на трейне MAE падает, а валидация выходит на плато
- Результаты совпали с гипотезой только для дерева. Видимо, другие модели получают нужную информацию из марки и модели автомобиля, а дерево все таки использует пороги и отношения новых признаков
- Гипотеза поддтвердилась. Бренд и модель действительно содержат информацию о цене, которую нельзя понять по другим признакам.
